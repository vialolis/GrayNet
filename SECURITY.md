# Security Policy

## Supported Versions

GrayNet is currently in **Beta (v0.1.0)**. Security updates are prioritized for the latest release.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within GrayNet, please do not open a public issue. 

Instead, report it via:
* **Private Reporting:** Use the "Report a vulnerability" button in the Security tab of this repository.
* **Direct Contact:** Reach out to me in our space/community chat (if you have access) for a faster response. (Matrix: #graynet-project:matrix.org)

I aim to acknowledge all security reports within 48 hours.
